# Sky Passport (航迹护照) — project memory for Claude Code

## What this is
A tool that turns a person's flight history into a ~60 s vertical (1080×1920, 30 fps) "flight passport" animation with original synthesized music.
Owner: Barry (BYB). Product language: Chinese-first UI, bilingual (中文/English) labels in the video.

Two codebases live here:

| `video-pipeline/` | Offline renderer used for Barry's personal film (v4). Headless Chrome renders frames → ffmpeg; Python synthesizes the score from the exported timeline. | Reference implementation; the web engine was ported from it |

## web/ architecture (page: `web/public/index.html` + classic scripts in `web/public/js/`; one serverless function: `web/api/check.js`)
- Scripts share one global scope and load in order: `core.js` (data, parsing, diagnosis, PRNG) → `engine.js` (scene, cover, page, map, render) → `music.js` (synth, mix) → `ui.js` (wiring, table check, row editor, quick years, segmented controls) → `extras.js` (QR end card, achievements, long poster, cover image) → `export.js` (save/export, boot). Top-level code may only use what earlier files define.
- Options (step 03, remembered in localStorage): 封皮颜色 `THEMES` (burgundy/navy/green/black), 配乐 groove/calm (calm drops the kick/snare grid, keeps crashes + motif), 片长 full/≈45 s/≈30 s (squeezes the year section only; the approved opening/ending are untouched, so ~18 s is the floor; short cuts judge sparse years by flight count `y.gap`).
- Sharing: the closing poster carries a QR + `SITE_URL` (extras.js — change it when a custom domain is live); 「生成长图海报」 (1080-wide PNG) and 「导出视频封面图」; achievements are computed in code (`computeBadges`). The 航旅纵横 export guide text lives in `GUIDE` (ui.js) — menu names were not verified against the current app; keep them in sync.
- Flags are per-country files `public/flags/XX.svg` (generated, git-ignored; no TW file), loaded on demand. Tests: `cd web && npm test` (node:test + vm, no deps).
- **China-facing map rules (keep)**: China is drawn from `china.json` (DataV.GeoAtlas/AutoNavi standard outline incl. Taiwan, 藏南, 阿克赛钦, South China Sea islands; regenerate with `npm run build:china`), the nine-dash line is always drawn, other countries' fills are clipped out of China's outline, Taiwan shows a neutral 「台湾」 marker instead of a flag, HK/MO/TW English names are "…, China". Formal publication of maps in China still requires a 审图号; this reduces, not removes, that risk.
- Saving: 「⬇ 保存视频」 appears under the preview after export; on phones it opens the share sheet (「存储视频」→ photo album); inside WeChat a banner asks the user to open the page in a browser.
- Data files fetched relatively at runtime: `airports.json` (OpenFlights IATA rows + 738 Chinese airport-name keywords + ISO numeric + country names), `world-50m.json` (world-atlas topojson), `china.json`, `flags/XX.svg` (regenerate with `npm run build:data` / `npm run build:china`).
- CDN scripts (pinned): d3 7.9.0, topojson 3.0.2, SheetJS xlsx 0.18.5, mp4-muxer 5.2.1, qrcode-generator 1.4.4. Vercel Web Analytics script is included (enable Web Analytics in the dashboard).
- Pipeline in the page: `readWorkbook` (sheet/column detection, 航旅纵横 export format incl. 待出行/已结束/无效票 sheets) → `buildFlights` (airport resolution: IATA → Chinese keyword longest-match → English city → manual IATA entry; tz-aware durations; dedupe) → `buildScene` (BPM-grid schedule, camera, countries; land/graticule/country outlines cached as `Path2D` per projection) → `renderFrame(i)` (deterministic, pure function of frame index) → `synth()` (music, same grid) → `exportWebCodecs` (H.264 10 Mbps/AAC MP4 via WebCodecs + mp4-muxer; falls back to VP9/Opus-in-MP4, then real-time MediaRecorder).
- Look (v2, 2026-10-09): poster = leather passport cover with debossed gold-foil emblem/title (`buildCover`, foil mask `foilCv`, light glint on open and on close); page has paper fibres, watermark emblem, engraved-silhouette photo placeholder, OVD rainbow rosette on the photo, graticule, route halo + gradient, plane ground shadow, flag gloss, ink-bleed stamp; seeded film grain on every frame (`grain(i)`).
- Audio (v3, 2026-10-10): buses dry (drums/leads) + bed (pad, FM keys, bass; side-chained to the kick) + an effects bus that is never ducked; dotted-8th ping-pong + Freeverb-style room shared by music and effects; master glue comp → −14 LUFS (BS.1770 measured in-page) → look-ahead limiter at −2.6 dBFS sample peak (≤ −1 dBTP after AAC). The 3-note motif (A–G–E over Fmaj7) is stated on every non-gap year downbeat, moved to that bar's chord, on a rotating instrument (celesta, marimba, kalimba, vibes, flute, glock; glass for dream years). The music stays synthesised (our own score).
- Sound effects follow the opus-sound-layer standard (https://github.com/Bodila51/opus-sound-layer): **real CC0 recordings only, never synthesised hits/clicks/whooshes**. 22 sounds live in `public/sfx/film.mp3` (one MP3 sprite, 154 KB; map `SFX_MAP` in music.js; a one-sample marker at 0.1 s lets `loadSfx()` correct each decoder's MP3 priming; credits in `public/sfx/CREDITS.md`). `filmCues(sc)` lists every cue from the picture's own timing: move = top speed (cover swing mid-point, long-haul plane at mid-flight), land = motion visibly stops (cover at 86 % of the eased swing), stamp on the contact frame (T_STAMP+0.16), hero = reverse cymbal → hit + sub boom + wood + paper after the hang. Each sound is placed by its own peak; small effects get per-event gain against the music in their band (up to 2.5×) and duck the music ≤6 dB for ~0.1 s if still masked; repeats vary pitch; long-haul whooshes are never stacked (≥0.8 s apart). `synth(sc)` also takes `sc.cues` (replace the list), `sc.stops` (dead stops before a hero) and `sc.stems` (QA stems with the real master gain).
- Sound QA (own scripts; running the repo's scripts was blocked as external code): integrated −14 ±1 LUFS, true peak ≤ −1 dBTP on the encoded MP4, every cue ≥ 0 dB over the music in its own band, hero/land/move cues within ±1–2 frames of the picture motion, no silence ≥0.5 s, every big full-frame change has a sound. Run it after any change to cues or gains.
- Server render (`web/server/render.js`, 2026-10-10): one shared Chromium (a launch race used to start one browser per warm page: 2.6 GB idle on a 3.7 GB box with no swap, which once froze the whole server incl. the BBQ site), 3 pages (not 4: each warm page holds ~400–530 MB and the box has MySQL, hermes and no swap; four left ~150 MB above the floor after a few hours) render frame ranges and each streams JPEGs into its own x264 (`-threads 1`) while drawing; segments are joined losslessly; only the first page synthesises the score (in its Worker, terminated afterwards), the others cancel the page's own auto-synth. Pages are recycled after 8 jobs. Server pages (`?render=`) skip the film grain (x264 crf 25 erased it anyway: same size, PSNR 40.5 dB). Watchdog: MemAvailable < 450 MB stops the job, closes the browser and retries it once with 2 pages (the user only sees it continue); the unit has OOMScoreAdjust=800. 31 s film: 57 s → 41–43 s, min MemAvailable 490–880 MB. Speculative pre-renders (`{spec:true}`, sent by the mini program after consent while the user reads the stats) only run on an idle box, are cancelled by any real request and adopted by a real request with the same input.
- The score is synthesised in a Web Worker built at runtime from the same functions (`synthInWorker`; falls back to the main thread), precomputed ~0.8 s after each rebuild; `ensureAudio()` returns a Promise.
- Ticker: departure-board roll between entries (0.12 s); the newest flight's plane leads, older planes in the air are smaller/fainter. Odometer clip = one glyph (48 px).
- Fonts: every CJK glyph used in the script (plus the user's name/tags) is preloaded by `ensureFonts()` before preview and export, so fonts never swap mid-video. Flags (SVG) are rasterised once to 96 px bitmaps.
- Demo data uses a fictional traveller (林小舟 / LIN XIAOZHOU); input placeholders are fictional too — never put the owner's real name in examples.
- Table check (step 01·B「检查表格」): `buildFlights` returns `diag` (unknown airport names with row refs, rows without dates + reason, unknown status texts, train/station-looking rows, same-airport, missing airport, duplicates). The panel shows each issue with sheet/row/column and guidance; fixes live in `manual` (name→IATA), `STFIX` (status→flown/upcoming/void), `EXCL`/`KEEP` (row keys). 「下载修正后的表格」 exports a clean CSV.
- AI check (opt-in button): the browser sends only cells needing judgment to `POST /api/check`; the function writes every question itself (Choice per unknown name over code-generated airport candidates + `none`, per unknown status, per suspicious row; column/header-row mapping when no table was recognised) and calls TypeSafe Jev (`jev-1.13.0`, pinned). Thresholds in the page: ≥0.85 one-click apply, 0.5–0.85 "please confirm", below that alternatives only. Key: Vercel env `TYPESAFE_API_KEY` (production + development; sensitive). The function rejects foreign `Origin`s and throttles per IP (best effort; add a Vercel Firewall rate limit if abused). Privacy copy on the page says exactly what is sent — keep it accurate if the payload changes.
- Local dev with the API: `cd web && vercel dev` (pulls the development env). `npm run dev` serves the static page only; the AI button then reports that the service is unavailable.
- When running as a claude.ai artifact, file saving goes through `claude.use('downloads')`; outside claude.ai it falls back to an `<a download>` link.

## Motion/music rules we settled on (keep these)
- 112 BPM grid; one chord per bar (Fmaj7–Em7–Dm7–Cmaj7). Every year starts on a bar line; map-only punch (1.03→1.0 over 20 frames) + crash on each year downbeat. Do NOT scale the whole page (small text shimmers).
- Pacing: sparse years (≤0.5 bar) = "gap" section (drums out, filtered pad); all-upcoming year = "dream" section.
- Ending = stop → hang (1 beat) → ink-stamp slam (SFX on contact frame, page shake) → groove returns with zoom-out + route light pulses → cover closes → poster.
- Opening = poster (2 bars) → cover swings open (0.8 s) → map prints row by row, MRZ types itself.
- Year counter is an odometer, clipped to one glyph height. Flight ticker shows only flight no. + IATA route (no dates).
- Determinism: all randomness via `hash()` / seeded PRNG; same frame index ⇒ same pixels (GPU anti-aliasing can still differ by ≤3/255 on a few hundred edge pixels between two renders; avoid `shadowBlur` and re-rasterised SVGs, which made it worse).
- Visual direction: 90s passport / guilloche security print; burgundy cover + gold foil on the site.
